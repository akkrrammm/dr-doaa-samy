# Dr. Doaa Samy — Clinic Website

> Official bilingual (Arabic / English) website for Dr. Doaa Samy, powered by a custom admin CMS.

🔗 **Live site:** [dr-doaasamy.com](https://dr-doaasamy.com/)

## ✨ Features

- 🌍 Bilingual Arabic (RTL) & English experience
- 📄 Pages: Home, About, Services, Articles, Videos, Patient Reviews & Contact
- 🛠️ Custom admin dashboard to manage page sections, treatments, media and site settings
- 🔍 Per-page SEO controls
- 🔐 Secure admin authentication
- 📱 Fully responsive, mobile-first design

## 🛠️ Tech Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · Supabase (Database, Auth & Storage)

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Add your Supabase environment variables to `.env.local` before running.
